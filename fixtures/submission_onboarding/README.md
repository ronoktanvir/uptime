# Authored contracts for the role 1 demonstration

Written for the November 9 submission. They are not derived from any evaluation corpus, sealed input, diagnosis or
real vendor agreement, and the vendor names are invented. They exercise the ordinary model-assisted onboarding
path: none is accepted by the strict offline parser, so Uptime must ask the model for a reading.

| File | Purpose |
|---|---|
| `halden_relay.json` | Positive: an unlabeled party statement and a tier table |
| `corvid_ledger.json` | Positive, worded differently: labeled sentences, different measurement, filing and remedy wording |
| `halden_relay_control.json` | Refusal control: conflicting filing windows and a maintenance exclusion |

A successful onboarding of these authored contracts is a demonstration, not an independent generalization score.
