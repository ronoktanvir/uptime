# Northwind financial walkthrough inputs

These are newly authored fictional contracts, invoice records, usage records and local signature specimens. Northwind Cloud is the fictional provider; Harborline Analytics is the fictional buyer. The package supplies no real-party execution, actual human approval, external certificate, live provider object or native write permission. CalyxQuay remains a separate public-source onboarding example.

`load_package()` in `fixtures.northwind.loader` returns the public SLA document, private scope overlay, compiled manifest, existing typed pricing agreement, three monthly fact sets, invoice inputs, pricing results and exact citations. It verifies original file hashes and local Ed25519 signature specimens. The private specimen key was generated locally and discarded; the public signature proves only integrity of these authored bytes. Scenario signature dates are distinct from the specimens' actual creation times. No operational reviewer identity or grant comes from this package.

The order sets the Cloud Hosting/Business fee and its ceiling to USD 12,000 per complete UTC month. The February 20 amendment explicitly sets both the fee and ceiling to USD 11,000 for March service onward. A ceiling alone would not establish the payable fee. The loader calls the existing pricing engine and takes the governing eligible line's expected amount as the SLA base. It does not use the billed amount, include taxes/non-covered charges, read expected results, or branch financial arithmetic on a vendor name. The supplied invoices separately itemize zero tax and contain no non-covered charge; negative tests add both taxes and excluded charges.

January contains 135 eligible unavailable minutes of 44,640. February contains 5 of 40,320 and is invoiced March 1 under the original USD 12,000 fee. March has incomplete usage coverage, so SLA eligibility is unknown, while its USD 12,000 billed service fee exceeds the governing fee by USD 1,000 before payment. Invoice exposure and SLA credit are distinct obligations.

`expectations.json` is a separate authored comparison artifact. The loader never opens it. Known ineligibility is distinguished from unknown by outcome and known zero credit units; the existing noneligible/unknown amount convention is `null`. No result from this package is an independent heldout proof or evidence of model generalization.

The current accepted step grammar is the complete sentence in `document.json`, with substituted bounded product/plan names and percentage values. It means completed full increments, explicit percentage cap, exact UTC month ratios, no intermediate rounding and one final HALF_UP cent rounding. The separate rounding clause is mandatory. “Started”, fractional-step, dollar-cap, conflicting tier, additional condition or alternate unsupported prose refuses. The claim interval is 30 full calendar days after the final service day, represented by the following month's first instant plus 30 days, exclusive. Original source offsets and SHA256 values remain available with every citation.

Workflow owners must ingest through existing authenticated service interfaces, retain scripted authority kinds and exact evidence scope, and use the current semantic-review requirements where the selected adapter requires them. This data package neither activates an adapter nor posts a provider record. Local destination receipts must retain their actual destination and namespace.

The current workflow uses a fresh isolated database with the existing internal `bears` rehearsal tenant, as approved in decision 66a. `Northwind` is the dataset/provider story, not an invented source-grant namespace. Customer and account identity remain Harborline Analytics / harborline-001; all source verifiers must bind the actual configured tenant. No native credentials or an existing workspace database belong in this fixture run.

The initial package freeze intentionally leaves March advance pricing unsupported until decision65a is implemented. The loader returns that pricing result with a null governing fee rather than stopping January's input preparation. Positive stepped SLA evaluation also remains gated on a trusted governing-fee context. Neither provisional gap may be presented as successful financial dispatch.

`usage.json` contains independently authored dated outage intervals, incident/component/region identity and status event references. Its declared monthly total must agree exactly with those intervals. `supplements.json` contains a January resource log and a separate verifier descriptor linked to that original status event; the workflow releases it only after the denial, at its March 2 observation time. `correspondence.json` contains fixed authored vendor messages and memo identity. Their amounts are input statements subject to parser, evidence and entitlement checks, never generated from an expected answer or current claim amount. The runtime filing receipt must be substituted only into the signed message envelope; text and declared memo identity remain unchanged.
