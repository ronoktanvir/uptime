# Prospective witness

The witness exercises the current mounted application through signed local APIs while preserving the frozen original input denominator. It changes no backend code and invokes no external model. A staged public-only extraction receipt is required. TestClient is supported for an isolated worker; the integration owner runs the actual loopback socket witness.

Run `witness.py --help` for arguments. Supply the frozen directory and its independently recorded manifest hash, public vendor/document labels, approved extraction directory, current `--app-root`, and optionally an exact `--app-sha`. The application path, commit, hashes of all Python application sources, extraction receipt hash, and witness snapshots are recorded locally. A source change during execution invalidates the run.

The harness uses `Overlay.public_agreement` through `/api/vendors/{id}/candidates`. It preserves the supplied agreement version and requires an exact, unique public version, title, service, plan, period, and input denominator join. It never replaces a substantive mismatch with a generated contract ID. The compiler must return the same source version and title.

Two explicitly synthetic public controls exercise shadow preview, review and activation: an entire-month outage with a newly declared USD 100 subscription, and missing monitor evidence. Their observations are sealed before independent Decimal arithmetic is compared with the public propositions. They are excluded from the original input denominator. All reviewer signatures, source keys and mandate issuers are isolated test actors; there is no human approval. The application's normal named-key API records `authenticated_reviewer`; that label is not evidence of a human participant.

Original observations use `service_monitor`, `service_invoice`, and an original `filing_proof` only if present. Projection preserves fractional minutes and cents, scope conflicts, invoice details and original timestamps. It never infers completeness from a month-shaped interval. Frozen file hashes and projected content hashes are recorded separately. A verified local hash establishes synthetic byte integrity, not provider confirmation. Generated fee references are explicitly local aliases. The declared subscription total must agree with the itemized recurring line; duplicate or ambiguous lines remain gaps.

Correspondence uses the signed aggregate events published in `tests/test_correspondence_service.py` (the implemented name of the anticipated aggregate test module), plus original artifacts and separate synthetic integrity verification. Original filing materials and receipts are forwarded only when supplied. An unfiled reply correlation probe is an explicit rejection control and cannot count as a measured denial.

`observations.json`, HTTP responses, projections, code snapshots and control receipts are sealed before `compare_sealed` opens any original oracle JSON. `result.json` contains the post-seal comparison. Earlier attempts are retained; all records and failures remain in the private local freeze's `runs/attempt-NNN` directories with restrictive permissions. No private reports are committed.
