# Test changes — side panel, November 10

Branch `work/submission-panel-20261110`. This ledger lists every **existing** test this branch changed, by exact name, with the reason. Tests that were only added are listed at the end.

No change weakens an assertion about money, authority or what reached Ramp. Every amount asserted before is still asserted as an exact string, and every "no write to Ramp" and "Not a live read" statement is still asserted word for word. `tests/test_side_panel_framing.py` is unchanged and passes (41 cases): the framing policy and the extension's permissions did not move.
