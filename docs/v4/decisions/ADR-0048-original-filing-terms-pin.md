# ADR 0048 — Immutable original filing source pins

## Decision

Require original filing economic-version and source-document digests for ACTUAL native award attribution. Validate the explicit pins during signed receipt intake and retain the original under later adapter changes. Independently signed attribution scopes also bind the exact original receipt hash.

## Alternatives and cost

A fresh witness alone could silently substitute current terms for historical terms. Rewriting an old receipt would erase provenance. Immutable optional intake fields preserve old records, while monetary attribution requires verified pins. Old unpinned receipts remain observed and reviewable. A supersession workflow remains explicit future work. The original [decision packet](packets/48-original-filing-terms-pin.md) retains the contemporaneous context and falsifiers.

## Verification

The 54-test root source-pin/procedural suite covers source tamper, wrong version, exact current public intake, retained original after catalog changes, and valid award attribution before and after approved zero-dollar replies. ## Rollback

Keep any failed or old unpinned award unallocated and preserve its evidence. A future superseding receipt must reference the original hash, retain both versions and require new independent witnesses. There is no automatic backfill from current contract interpretation.
