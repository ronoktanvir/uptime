## Parent assessment and disagreement

D1 is conditional on an absent intake boundary, which the reviewer explicitly did not inspect. The ordinary delivery signature covers the exact JSON envelope including `scope` (`auth.service_message` hashes the raw body). `SourceGrant.allows` parses the typed delivery, and `source_config.event_in_scope` requires exact scope equality against the independently enrolled grant. `CorrespondenceDesk._receive` again requires `scope == event.scope` and derives the retained evidence digest from that scope. Account, service and month therefore come from the authenticated delivery assertion, not a default invented by the join. A repeated body field may be absent; if present it must agree. Requiring the same identity a second time in every line/report would add redundant wire requirements without addressing a new authority gap. Prior invoice issue time does not determine its fee month; the authenticated billing envelope does. This is a scoped source assertion, not independent proof that the underlying customer invoice is truthful.

D2 is excluded by the schema the reviewer explicitly did not inspect. `correspondence_types.Amount` accepts only bounded nonnegative decimal strings with at most two fraction digits. `Invoice.model_validate` runs before any `Decimal` conversion. Added parent controls reject Infinity, NaN, negative strings, exponential notation, arbitrary text, float, boolean and null with the existing ValueError refusal. A verified zero fee remains a legitimate observed value and the unchanged evaluator returns no positive credit; replacing it with a positive-only rule would lose that distinction.

L1 remains a contextual-source limitation: the marker is available only through the source-derived compiler and version-bound review. Unrecognized source clauses are unsupported; exact-span recognition alone does not replace reading or approving the governing source. This workstream does not automate human review.

The review confirmed the corrected two-source policy, optional corroboration, present-null refusal, strict receipt chronology, original filing preservation and material overlapping evidence-basis conflicts. The parent retains the implementation, adds the amount controls, and records the review's scope rather than presenting its conditional concerns as reproduced defects.
