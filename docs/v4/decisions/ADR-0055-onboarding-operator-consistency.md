# ADR 0055 — Consistent operator hints and bounded public diagnostics

## Decision

Share the compiler's existing within-block whitespace normalization with extraction hints. Keep original source bytes, offsets and hashes. Restrict the existing no-minimum-duration operator to affirmative templates with conservative refusal of conflicting or unsupported duration conditions. Retain validator enforcement of evidence authority. Produce any detailed rejected-source diagnostic offline as an explicitly selected, content-addressed public attachment.

Implementation and independent verification are in progress. The original rejected model proposal retains its recorded status.

## Alternatives and review

A whitespace-only fix would retain demonstrated false positives. Open-ended clause interpretation adds ambiguity. Exact affirmative templates plus existing independent operators provide a bounded correction. A normal-intake scan of the rejection archive would couple quarantine history to candidate creation, so the selected diagnostic design uses an explicit offline attachment and existing trusted public-artifact configuration where available.

Accept the exact-template, validator-authority and safe-diagnostic requirements. A fixed reason-code table supplies explanations. Public quotations must come from byte-exact approved source slices and match their hashes. Private overlay errors retain generic redaction. A prompt clarification changes the extraction configuration, so any later model attempt requires a fresh receipt and the existing interpretation and promotion review.

The proposed blanket NBSP refusal would regress existing compiler behavior. Baseline testing confirmed that the compiler accepts equivalent ordinary-space, line-feed, carriage-return, tab and NBSP forms while preserving their distinct source bytes. Share that established normalization. Hyphenated words and zero-width characters retain separate unresolved treatment. This disagreement preserves compatibility while keeping source provenance exact.

## Verification requirements and falsifiers

Separate commits must isolate whitespace consistency from the affirmative-template guard. Re-run all committed vendor-source tests after each, explaining every acceptance change. Test both orders of contradictory duration clauses, unrelated minimum invoice fees, quoted examples, conditional qualifiers and supported clipping/fixed-denominator neighbors. A claimant custodian verifying its records must never acquire issuer-verification authority.

Diagnostic tests must reject mismatched source, receipt, offset or quote hashes, raw model rationale, arbitrary exception text and client-supplied paths. Repeated reads must preserve rejected receipt and source bytes. Actual intake and human promotion remain distinct acceptance steps. The authorized engineering remediation covers this reversible change, while commercial and financial actions retain their separate authority requirements.

## Rollback

Revert a predicate or normalization change that alters supported source meaning or admits unsupported authority. Disable diagnostic attachment loading if any privacy or binding negative control succeeds. Preserve old proposals and all evaluation attempts, then repeat the same tests on the corrected source.
