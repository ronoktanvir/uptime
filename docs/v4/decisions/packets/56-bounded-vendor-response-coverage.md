## Proposed architecture

Use one decimal-safe clause representation and finite, whole-clause templates for the affected existing families. Preserve original source offsets and every substantive clause. A recognized keyword never authorizes a proposal by itself. Compose only compatible typed assertions; an unmatched clause, mixed target, unsupported condition, quote, waiver or unfamiliar obligation makes the entire reply review-only. Avoid maintaining a permissive cue regex and a contradictory completeness grammar as two separate language authorities.

1. **Availability.** Templates cover an availability subject with an optional numeric percentage, a definite meets/exceeds/at-or-above predicate and a target noun with an optional percentage; the reverse target-subject/passive form is also bounded. Decimal points stay inside percentage tokens. Percentages are untrusted quoted assertions, never fee, threshold, rate or entitlement operands. The actual reviewed contract and signed measurements alone determine valid denial or correction. Reject malformed/out-of-range percentages and uncertain/conditional language. An explicit service-period qualifier must match the server-supplied claim month. Initially support exact ISO `YYYY-MM`, fully qualified English month/year, or the explicit anaphor `the service month`; ambiguous years, relative dates, different months or new service subjects refuse. Add only server context needed for this comparison, not a caller-selected period override.
2. **Lateness.** A bounded `it` can refer to the current claim only when an explicit claim/request/filing antecedent occurs in the same denial construction or immediately preceding recognized acknowledgment, with no competing subject. Bare `it`, an invoice antecedent, hedging, or another unmatched proposition refuses. Actual original receipt and contractual cutoff still determine the disposition; alleged vendor timing is not substituted for those facts.
3. **Missing artifact plus request.** Parse a definite missing/not-received declaration and a request as two assertions. Unify one artifact type and reference. An immediately following `that document`/`it` may inherit the already explicit artifact; it cannot select another type or ID. Conflicting references/types or a negated missing claim refuse. Existing independent artifact content/verification, same-scope linkage, allowed disclosure, original deadline, reviewer approval and one-supplement checks remain mandatory.
4. **Partial awards.** Map every USD token in fully consumed clauses to exactly one grant, stated original claim, or denied remainder. Support bounded conjunction/prefix/remainder forms within those roles. Require one positive grant no larger than the immutable filed claim, an explicitly restated claim equal to that claim, and grant plus stated remainder equal to it. Use exact existing cent arithmetic; repeated or unexplained amounts, other currencies, conditions, quotations or unmatched text refuse. A parser proposal alone never creates an award, response or authorization.

This remains a finite English grammar, not general freeform understanding. Unknown constructions continue to human review. Period matching and evidence validation are independent of the vendor's assertions. Source identities, field mappings, original pins, filing authority and monetary stages are unchanged.

## Alternatives and costs

- **Keep the current finite grammar and send all new wording to review.** Lowest implementation risk, preserves current coverage failure and does not satisfy the caller-authorized normal workflow objective.
- **Shared finite clause templates and typed composition (recommended).** Fixes a demonstrable architectural drift between cue detection and complete coverage. Deterministic, auditable, modest runtime cost; still requires explicit coverage additions and honest abstention outside the grammar.
- **Runtime model proposes structured assertions and quote spans, with the same independent deterministic full-coverage/scope/evidence/conservation gate.** Useful for proposals or review explanations, but it cannot authorize arbitrary unrecognized text. If verification still recognizes only the finite grammar, it does not itself broaden automatic coverage and adds latency/model availability. A proposal cannot attest a source, define a period, invent consent or create a financial operand.
- **Model-only interpretation plus downstream numeric/scope checks.** Broader language coverage but insufficient: numeric correctness would not reveal a skipped settlement waiver or conditional grant. Not proposed for automatic disposition or financial stages. A separately evaluated advisory lane could retain unknown text for a human.
