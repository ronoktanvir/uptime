# ADR 0065a — Governing fee context and fixed-month advance timing

Status: actual independent review received; implementation decision pending root review.

The preserved [public packet](packets/65a-governing-fee-authority-and-fixed-month-advance.md) was reviewed by actual tool-free `claude-opus-5-5`, session `0f67791d-a8a8-46cd-a7e5-a53c36d83518`. Its complete [response](reviews/65a-governing-fee-authority-and-fixed-month-advance.json) conditionally recommends separate governing-fee and advance-timing changes. Neither is implemented by this ADR.

The strongest objection is correct: an arrears invoice quantity of two could otherwise double the pricing engine's expected line and therefore the SLA base. The preferred advisory alternative resolves contractual fixed fees without an invoice; its acceptable narrower alternative requires the contract itself to fix quantity, refuses invoice mismatch and explicitly leaves absent or duplicate invoices unsupported. The local recommendation chooses the narrower alternative for this deliverable. It does not synthesize an invoice or treat a ceiling as a fixed fee. The source must establish one fixed subscription unit for every applicable month, including arrears months.

Context issuance must resist `dataclasses.replace`, shallow/deep copies and deserialization. A private issued-instance identity set or keyed canonical digest is required; a copied token field is insufficient. Immutable server registry entries, exact authenticated envelope and complete signed invoice body, SLA source/overlay, pricing source/version/input and dependency hashes, and the original signed-evidence digest must bind the result. Persist only the digest and re-resolve at each current evaluation. Full-process malicious Python remains outside that seal's protection.

The local recommendation also accepts observation-time constraints for advance pricing: require a trusted `as_of`; refuse any supplied term signed after that observation rather than adding a general historical knowledge filter. Existing refusal of late-signed retroactive terms remains. A new source/input revision stales dependent assessment; it cannot rewrite historical receipts. A fixed-month timing clause must be demonstrably in force. The authored amendment can explicitly restate its unchanged billing timing, avoiding any implicit inheritance engine. Exact service start and one full UTC month remain the only supported advance timing.

Two advisory points need root choice. First, the adviser rejects any exact-clause grammar and would route timing semantics through decision61. The local recommendation preserves the repository's narrow deterministic source compiler model: an exact affirmative template can establish a bounded operator without heuristic interpretation, with full-source material coverage and source/version proof. This is not an external authority claim. A generic new legal approval service would widen scope. Second, the adviser prefers no fee dependency for known ineligible zero; the implementation should retain a known zero credit rate even when no fee context exists, while preserving the existing null nonclaimable amount convention. Unknown availability and missing positive-credit fee context cannot become a partial monetary sum.

Source classification and actual authorization are retained. Local synthetic input, signatures, scripted review and destination receipts do not become real contracts, actual-human judgment or native provider proof. Root owns product presentation choices from decision64. The finance context may carry USD/minor exponent2 and provenance without creating a hidden demo/provenance bypass.

Pending falsifiers include arrears quantity2, missing/duplicate invoices, forged/copied/stale contexts, mismatched invoice body/envelope, future-known terms, changed source spans, exact-start versus one-microsecond offsets, incomplete usage, variable or partial quantities, and unchanged historical economic identity. January processing must work independently of advance support; unsupported advance March exposure must remain unknown.
