# ADR 0044 — Reusable contractual evidence primitives

Status is implemented with external and acceptance limits recorded in STATUS.md.

## Decision and alternatives

Extend finite typed families for complete subscription intervals, region/edition scoping, intersection of independently attributed telemetry, paid-net refunds and separately anchored original/supplement deadlines.

The frozen failures exposed legitimate contractual mechanisms. A reusable, versioned interpretation can support multiple contracts with deterministic fee/time math. Unknown or incomplete evidence still blocks entitlement.
