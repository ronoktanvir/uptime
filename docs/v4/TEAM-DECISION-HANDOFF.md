## Decisions already made: do not reopen routinely

Ramp remains the financial system of record. The companion supports evidence, onboarding, disputes and investigation; it is not a replacement accounting application. Existing code and history stay intact. Onboarding and dispute engineering retain equal priority.

Financial calculations, eligibility, effective dates, exclusions, deadlines and authorization remain deterministic and typed. Unknown money stays unknown. Estimates, filed amounts, awards, posted credits and applied credits are not summed as independent recovered value. Models propose interpretations; they do not supply financial or action authority. Generated adapters remain declarative and do not execute arbitrary generated code.

The product uses ordinary financial language without repeated demo/synthetic/replay badges or hidden mode indicators. Existing source identity, authority and audit fields remain intact. A local ledger receipt cannot be presented as a successful Ramp write; a seeded reviewer cannot be presented as an actual human decision. The presentation and handoff explain authored data.

Preserve original failures and exact source versions. Never rewrite expected outcomes to make a test pass. Keep credentials, private operator databases and sealed evaluation answers outside Git and external model prompts. Continue focused GitHub commits and the agreed full regression after integration merges.
