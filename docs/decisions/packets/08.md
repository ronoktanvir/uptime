Public-source allowlist, opt-in tool-free authenticated Claude for extraction, evidence investigation and explanation. Treat proposed rules/fact refs as untrusted data; require strict schema, citations, replayable provenance, bounded inputs and deterministic gates. Guide read-only and tenant-bound, approvals separate; alternatives blanket external model of private docs or fixture-only. Test forged refs, tool suggestions, malicious text, secrets and role bypass. No confidential data to model.

Evidence at review: empty application repository, checked handoff, available isolated worktrees; tests listed above are acceptance targets. Implement only reversible sandbox steps. Rollback: disable the surface, retain prior immutable state and run offline fixtures.
